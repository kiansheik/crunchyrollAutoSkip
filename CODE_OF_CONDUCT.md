# Code of Conduct

This project welcomes users, contributors, and forks from anyone interested in a simple, privacy-preserving browser extension.

## Expected Behavior

- Be respectful and direct.
- Keep discussion focused on the extension, browser behavior, documentation, and user impact.
- Assume good intent when asking clarifying questions or requesting changes.
- Report bugs with enough detail for someone else to reproduce them.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Doxxing or sharing private account information.
- Spam, self-promotion unrelated to the project, or deceptive store-publishing advice.
- Requests to add tracking, credential collection, or functionality that violates user trust.

## Enforcement

Maintainers may edit or remove comments, close issues, block users, or decline contributions that do not fit these standards.

If you are not sure whether a contribution fits the project, open an issue first and ask.
